# ObsidiaDoom vendor port

Source: `/home/zawe/Загрузки/esp32-doom-master`, supplied by the project owner.
It is Espressif's ESP32 PrBoom proof-of-concept, adapted here for ESP32-S3,
modern ESP-IDF partition mapping, Bruce's TFT backend and M5Stack CardKB.

The PrBoom engine sources are GPL-2.0-only; see `COPYING` and `AUTHORS`.
Espressif compatibility code retains its original license notices. The
`doom1-cut.wad` asset is preserved byte-for-byte from the supplied tree:

`SHA-256 1e745afe1867507ea3fda7f8dfac6dded0e905216b9ec610275b433f1f0bb8b1`

Do not replace it with a commercial Doom WAD in this repository.
